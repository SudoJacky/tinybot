# 输入与 Agent 设置

模型连接见 [Provider 与模型](./models.md)，主题与宠物外观见 [桌面宠物](./desktop-pet.md)。本页说明影响输入方式和 Agent 行为的设置。

## 富文本输入与语言

打开 **设置 → 应用偏好设置**，选择界面语言，或切换 **Composer 启用富文本**。

富文本模式可在输入框中编辑 Markdown 标题、列表和表格；关闭后使用纯文本编辑。切换会立即应用到聊天和快捷聊天输入框，并保留当前草稿。富文本模式下 Enter 发送或选择当前建议，Shift+Enter 用于换行或继续列表。

## 自定义指令

打开 **设置 → 个性化**，填写希望每次任务遵循的长期偏好与工作约定，点击 **保存自定义指令**。修改从下一次 Agent 任务开始生效。

> 默认使用中文。分析文件时先给结论与证据；缺少信息时明确指出。修改文件后说明修改位置和验证方法。

项目里的 `AGENTS.md` 可以补充更具体的项目约定。某次任务独有的要求放在该次对话中；需要按用户或工作区管理事实时，使用 [记忆管理](./memory.md)。

## Agent 默认设置

在 **设置 → Agent 默认设置** 调整会话没有单独指定时使用的配置，保存后再开始任务验证。

| 设置 | 作用 |
| --- | --- |
| 时区 | 为 Agent 提供时间上下文；定时任务仍使用电脑本地时间 |
| 最大输出 Token | 限制单次模型生成的输出规模；留空使用 Provider 的模型默认值 |
| 上下文窗口策略 | 选择丢弃旧消息，或先压缩总结较早的对话 |
| 最大工具迭代次数 | 限制 Agent 的工具迭代；不是整个任务的 Token 或费用预算 |

压缩会产生新的模型调用，摘要也可能遗漏细节。长期任务的重要要求应保留在文件或明确指令中，不要仅依赖旧对话始终完整地进入模型上下文。聊天中也可使用 [手动压缩](./chat.md#上下文空间与压缩)。

## 自定义快捷键

打开 **帮助 → 快捷键**，搜索要修改的命令，按页面提示录入组合键。遇到冲突先调整现有绑定；可清除单项或 **全部恢复默认**。

截图、菜单或手册中的按键以默认配置为例。修改后应以自己的快捷键列表为准。

## 实验室

**设置 → 实验室** 的功能默认关闭，可能继续调整。当前 Action Fusion（动作融合）允许模型把补丁与后续命令放在一次操作中，减少模型往返。

启用后从新的 Agent 轮次生效。补丁成功后才执行后续命令；后续命令失败不会自动撤销已写入的修改。若命中需要分步处理的命令 Hook，Agent 仍需分步执行。实验设置不是修复模型连接或工具配置错误的通用开关。
