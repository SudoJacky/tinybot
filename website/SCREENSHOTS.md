## 怎么补图

1. 按下面的说明截取真实应用界面，使用演示任务和文件夹。
2. 导出为 **WebP**，使用表格中对应的文件名。
3. 放到 `website/content/public/screenshots/`。
4. 运行 `npm run help:build`，再运行 `npm run help:preview` 检查；如果预览服务已启动，构建后重启预览服务，以加载最新产物。

建议按正常显示比例截图，宽度约 1440–1920 像素，裁掉无关桌面；局部操作可以只截取面板。不要为满足尺寸而放大低分辨率截图。文字较多时优先使用无损 WebP，否则调整质量到文字清晰；可以先以每张 300 KB 左右为目标，清晰度优先。

保留必要的导航入口、操作字段和相关状态。隐藏 API Key、token、认证头、个人路径、账号和真实任务内容。编号用于对照清单，不必把编号画进截图。

当前 Graph 编辑图包含失败记录，正文已说明；运行结果图展示“已完成”但仍在追问的节点回复，正文同时说明执行结束与任务达成的区别。
