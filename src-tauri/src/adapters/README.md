# Adapters
<!-- tinybot-module-fingerprint: sha256:91c2f4f94382fc7bbeff7ce900a2e0215f937a842bf9b1f9e44d6bcd14f3ea3a -->

`adapters` contains transport-specific adapters for external services.

- `mcp_http.rs` connects to MCP servers over HTTP.
- `mcp_stdio.rs` connects to MCP servers through child-process standard I/O.
